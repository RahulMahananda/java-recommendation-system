# Java AI-Based Recommendation System

A simple recommendation system built using Java that suggests products based on user preferences and collaborative filtering logic.

## Features

- Product recommendation engine
- User preference analysis
- Collaborative filtering
- File handling using data.txt
- AI-based recommendation logic

## Technologies Used

- Java
- Java Collections Framework
- File Handling
- Recommendation Logic

## Project Structure

RECOMMENDATION-SYSTEM/
├── RecommendationSystem.java
├── data.txt
├── README.md

## How It Works

- User preferences are stored in data.txt
- The program reads the data
- Similar users are identified
- New products are recommended

## How to Run

Compile:
javac RecommendationSystem.java

Run:
java RecommendationSystem

## Sample Output
